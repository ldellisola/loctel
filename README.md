# loctel

loctel is a native macOS menu bar app that receives OpenTelemetry traces and
logs from services running on your machine (in Docker or directly on the
Mac), shows them in a fast window with a service map, traces and logs, and
exposes the same data to AI coding agents over MCP, so a failed request can
be traced to the service and exception that broke it in seconds. It is built
and maintained by AI agents, so the repository carries all its own context:
start with [AGENTS.md](AGENTS.md).
